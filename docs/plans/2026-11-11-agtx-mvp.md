# agtx MVP — implementation plan

**Date:** 2026-11-11
**Goal:** lightweight, read-only terminal observer for agent-driven changes.
**Stack:** Rust + ratatui + crossterm, `notify` for filesystem events, git via CLI.
**Scope:** repositories up to 2–3 thousand files. No git write operations. No agent hooks in the MVP (interface reserved).

## Product behavior

- Full project tree (tracked + untracked non-ignored files), directories expandable/collapsible.
- Changed files color-coded: M/A/D/R/C/U/?.
- Selecting a file shows all uncommitted changes in the right pane.
- `e` opens the selected file in the editor profile from the TOML config.
- Filesystem events refresh the tree within ~200 ms; files touched in the last 10 seconds get a `●` marker.
- Nothing is ever written to the observed repository.

Non-goals for the MVP: staging, commits, branches, search overlay, syntax highlighting, agent hooks, mouse support.

## Global constraints

- Rust stable, edition 2021. Work from `/Users/macbookpro/Projects/agtx`.
- Git only through the CLI. Every call uses:
  `git --no-optional-locks -C <root> ...`
  with env `LC_ALL=C`, `GIT_PAGER=cat`, `GIT_TERMINAL_PROMPT=0`.
- Read-only: never run git commands that write the index, refs, or worktree.
- Dependencies only: `ratatui = "0.29"`, `crossterm = "0.28"`, `notify = "8"`, `clap = { version = "4", features = ["derive"] }`, `serde = { version = "1", features = ["derive"] }`, `toml = "0.8"`, `anyhow = "1"`. Dev: `tempfile = "3"`.
- Config path: `$XDG_CONFIG_HOME/agtx/config.toml`, else `$HOME/.config/agtx/config.toml`. Missing default file means defaults; an explicitly passed `--config` path that does not exist is an error.
- Defaults: `refresh_debounce_ms = 200`, `max_diff_bytes = 2_000_000`, `max_diff_lines = 20_000`, `show_untracked = true`, `ignore_dirs = ["target", "node_modules", ".git"]`.
- Default editor profiles:
  - `nvim`: `["nvim", "+{line}", "{file}"]`
  - `helix`: `["hx", "{file}:{line}"]`
  - `vscode`: `["code", "-g", "{file}:{line}"]`
  - Default profile: `nvim`. `{line}` is replaced with `1` when no line is known.
- Colors: Modified Yellow, Added/Untracked Green, Deleted Red, Renamed/Copied Cyan, Unmerged Magenta, recent LightGreen + BOLD, selected row REVERSED, directories BOLD.
- Symbols: `M A D R C U ?`, directories `▾`/`▸`, recent files `●`.
- Keys: `q`/Ctrl+C quit; `j`/`k`/Up/Down move; `g`/`G` first/last; `Enter` expand dir or open diff; `Space` toggle dir; `Tab` switch focus; `Esc` back to tree; `s` staged/all toggle; `f` changed-only; `r` refresh; `e` editor; PgUp/PgDn and Ctrl+u/Ctrl+d scroll the diff.
- No `unsafe`. No `unwrap()`/`expect()` outside tests. Errors carry context.
- UI text in English; comments sparse.
- Commit messages: Conventional Commits, ending with:
  `Co-Authored-By: Claude Code <noreply@anthropic.com>`
- After every task: `cargo test` and `cargo build` must pass with no warnings from our code.
- No implementer may dispatch subagents.

## Shared interfaces (binding across tasks)

```rust
// config.rs
pub struct Config {
    pub refresh_debounce_ms: u64,
    pub max_diff_bytes: usize,
    pub max_diff_lines: usize,
    pub show_untracked: bool,
    pub ignore_dirs: Vec<String>,
    pub editor: EditorConfig,
}
pub struct EditorConfig { pub default: String, pub profiles: HashMap<String, EditorProfile> }
pub struct EditorProfile { pub command: Vec<String> }
pub fn load(path: Option<&Path>) -> anyhow::Result<Config>;
pub fn default_path() -> anyhow::Result<PathBuf>;

// git/status.rs
pub enum StatusKind { Modified, Added, Deleted, Renamed, Copied, Unmerged, Untracked, Unknown }
pub struct FileStatus {
    pub path: PathBuf,          // repo-relative
    pub index: char,            // '.', 'M', 'A', 'D', 'R', 'C', 'U'
    pub worktree: char,         // '.', 'M', 'D', 'U'
    pub kind: StatusKind,
    pub orig_path: Option<PathBuf>,
    pub staged: bool,           // index != '.'
}
pub struct GitState {
    pub branch: Option<String>,
    pub files: BTreeMap<PathBuf, FileStatus>,
    pub additions: usize,
    pub deletions: usize,
}
pub fn parse_status(input: &[u8]) -> anyhow::Result<(Option<String>, BTreeMap<PathBuf, FileStatus>)>;
pub fn read(root: &Path) -> anyhow::Result<GitState>;

// git/files.rs
pub fn visible(root: &Path, status: &GitState) -> anyhow::Result<Vec<PathBuf>>;

// git/diff.rs
pub enum DiffLineKind { Header, Hunk, Context, Add, Del, Meta }
pub struct DiffLine { pub kind: DiffLineKind, pub text: String, pub old_no: Option<u32>, pub new_no: Option<u32> }
pub struct DiffView { pub path: PathBuf, pub staged: bool, pub lines: Vec<DiffLine>, pub truncated: bool, pub binary: bool }
pub fn load(root: &Path, rel: &Path, staged: bool, max_bytes: usize, max_lines: usize) -> anyhow::Result<DiffView>;
pub fn parse(text: &str, path: PathBuf, staged: bool, truncated: bool) -> DiffView;

// tree.rs
pub struct Counts { pub changed: usize, pub added: usize, pub deleted: usize, pub untracked: usize }
pub struct Row {
    pub node: usize, pub depth: usize, pub name: String, pub path: PathBuf,
    pub is_dir: bool, pub status: Option<FileStatus>, pub counts: Counts,
    pub has_changed_descendant: bool, pub collapsed: bool,
}
pub struct Tree;
pub fn build(paths: Vec<PathBuf>, statuses: &BTreeMap<PathBuf, FileStatus>) -> Tree;
pub fn set_changed_only(&mut self, value: bool);
pub fn update_statuses(&mut self, statuses: &BTreeMap<PathBuf, FileStatus>);
pub fn rows(&self) -> &[Row];
pub fn toggle_collapse(&mut self, row: usize) -> bool;
pub fn expand_all(&mut self);
pub fn collapse_all(&mut self);
pub fn find_row(&self, path: &Path) -> Option<usize>;

// app.rs
pub enum Focus { Tree, Diff }
pub enum AppEvent { Key(crossterm::event::KeyEvent), Resize, FsChanged(Vec<PathBuf>), Tick, Error(String) }
pub struct App;
pub fn new(root: PathBuf, config: Config, git: GitState, paths: Vec<PathBuf>) -> App;
pub fn handle_event(&mut self, event: AppEvent);
pub fn on_key(&mut self, key: KeyEvent) -> anyhow::Result<()>;
pub fn refresh_git(&mut self) -> anyhow::Result<()>;
pub fn open_selected_diff(&mut self) -> anyhow::Result<()>;
pub fn reload_diff(&mut self) -> anyhow::Result<()>;
pub fn edit_target(&self) -> Option<(EditorProfile, PathBuf)>;
pub fn mark_recent(&mut self, paths: &[PathBuf], now: Instant);
pub fn prune_recent(&mut self, now: Instant);
pub fn is_recent(&self, path: &Path) -> bool;

// watch.rs
pub fn should_ignore(path: &Path, root: &Path, ignore_dirs: &[String]) -> bool;
pub fn spawn(root: &Path, config: &Config, tx: mpsc::Sender<AppEvent>) -> anyhow::Result<notify::RecommendedWatcher>;

// editor.rs
pub fn substitute(args: &[String], file: &Path, line: Option<u32>) -> Vec<String>;
pub fn launch(root: &Path, profile: &EditorProfile, file: &Path, line: Option<u32>) -> anyhow::Result<()>;

// ui/mod.rs
pub fn draw(frame: &mut ratatui::Frame, app: &App);
```

All `PathBuf` values in state are repo-relative except the root itself. Git commands run with `-C root` and relative paths after `--`. The editor receives an absolute path.

## Task 2: Git data layer and tree model

**Files:** `src/git/mod.rs`, `src/git/status.rs`, `src/git/files.rs`, `src/git/diff.rs`, `src/tree.rs`, `src/main.rs`.

Implement all git reading and the tree, with tests. No rendering.

Requirements:
1. `git/mod.rs`: `pub fn repo_root(start: &Path) -> Result<PathBuf>` via `git --no-optional-locks -C <start> rev-parse --show-toplevel`; `pub fn run(root: &Path, args: &[&str]) -> Result<std::process::Output>` applying the global env and `-C root`. Trim the trailing newline from `repo_root`.
2. `status.rs`:
   - `read` runs `git --no-optional-locks -C <root> status --porcelain=v2 -z --branch --no-ahead-behind --untracked-files=normal`.
   - `parse_status` splits on NUL and handles headers `# branch.head <name>`, ordinary `1`, rename/copy `2` (the next NUL token is the original path), unmerged `u`, untracked `?`, ignored `!` (skip). Unknown records are skipped.
   - Path bytes are preserved on Unix via `OsStrExt::from_bytes`; on non-Unix use lossy UTF-8.
   - `staged` is `index != '.'`. The primary kind comes from the worktree code if present, else the index code. `R`/`C` with an original path set `orig_path`.
   - `read` also runs `git --no-optional-locks -C <root> diff --numstat HEAD --` and sums additions/deletions; `-` counts as 0. If `HEAD` does not exist, leave both at 0 instead of failing.
3. `files.rs`: `visible` runs `git --no-optional-locks -C <root> ls-files -z -c -o --exclude-standard`, splits on NUL, returns sorted deduplicated repo-relative paths, and unions in every path from `status.files` (covers staged deletions absent from the index).
4. `diff.rs`:
   - `load` chooses the command: untracked (`git ls-files --error-unmatch -- <rel>` fails) uses `git --no-optional-locks -C <root> diff --no-index --no-color -- /dev/null <rel>`; `staged` uses `git diff --cached --no-color --no-ext-diff -U3 -- <rel>`; otherwise `git diff HEAD --no-color --no-ext-diff -U3 -- <rel>`. A missing `HEAD` falls back to `git diff --cached`.
   - `--no-index` exit code 1 is success. Other non-zero exits return an error containing stderr.
   - Truncate captured stdout to `max_bytes` (print a byte-level truncation marker in `truncated`) and parse at most `max_lines` lines.
   - `parse` handles `diff --git`, `index `, `--- `, `+++ `, `@@ -a,b +c,d @@`, context ` `, add `+`, delete `-`, `\ No newline at end of file`, and other meta lines. Hunk lines carry old/new line numbers; hunk header counters start from the parsed starts. `Binary files ... differ` or `GIT binary patch` sets `binary = true`.
5. `tree.rs`: build from paths plus statuses:
   - root node index 0; directories and files inserted by path components; children sorted directories first, then case-insensitive name.
   - collapse state is keyed by **path**, not node id, so rebuilds preserve it.
   - `rows` is a DFS of expanded nodes, skipping the root; `changed_only` hides unchanged files and directories without a changed descendant.
   - `Counts` aggregates `changed` (any status), `added` (Added + Untracked), `deleted`, `untracked`; `has_changed_descendant` is true for a file with a status or a directory with at least one such descendant.
   - `toggle_collapse` returns false for files; `update_statuses` recomputes statuses/counts and rebuilds rows.
6. `main.rs`: after loading config, resolve the repo root from `args.path`, call `status::read` and `files::visible`, and print `root`, `branch`, `files`, `visible`, `+additions/-deletions` as one line each. Keep the Task 1 config line.
7. Tests:
   - status parser: ordinary modified, untracked, staged addition, rename with two NUL tokens, unmerged, branch header, non-UTF8 path on Unix.
   - diff parser: sample with header/hunk/add/del/context and correct old/new numbers; binary marker; no-newline marker.
   - tree: nested build, collapse/expand, counts, changed-only, find_row.
   - one integration test with `tempfile`: `git init`, write `a.txt`, `git -c user.name=T -c user.email=t@example.com add`, commit with the same `-c` flags, modify `a.txt`, add untracked `b.txt`; assert `read` sees both and `visible` contains both.

Acceptance: `cargo test` passes; `cargo run -- <temp-repo>` prints the summary.

Commit: `feat: add git status, file list, diff parsing, and tree model`.

## Task 5: Filesystem watcher, editor launch, final wiring

**Files:** `src/watch.rs`, `src/editor.rs`, `src/main.rs`, `src/app.rs`, `README.md`.

Complete the MVP.

Requirements:
1. `watch.rs`:
   - `should_ignore` is pure and testable: true for any path under a `.git` component, whose first component after root is in `ignore_dirs`, whose file name is `.DS_Store`, or that ends in `.swp`.
   - `spawn` uses `notify::recommended_watcher` recursively on root. The event closure filters paths and sends batches to a debounce thread; the debounce thread coalesces for `refresh_debounce_ms`, deduplicates, and sends `AppEvent::FsChanged`. Watcher errors become `AppEvent::Error`. Return the watcher so the caller keeps it alive.
2. `app.rs`:
   - `FsChanged`: convert absolute paths to repo-relative (drop paths outside root), mark them recent, call `refresh_git`, reload the open diff, preserve selection, set status `updated`.
   - `mark_recent`/`prune_recent`: keep entries for 10 seconds; pruning sets `dirty` only when something was removed. `is_recent` is used by the tree pane.
   - `edit_target`: returns the configured profile and the absolute selected path; `None` on a directory or when the default profile is missing (status line explains).
3. `editor.rs`: `substitute` replaces `{file}` with the absolute path and `{line}` with the line or `1`, in every argument. `launch` runs the command with `current_dir(root)`, inherits stdio, and errors with context if spawn fails or the process exits non-zero.
4. `main.rs`: on `e`, call `app.edit_target()`, then `ratatui::restore()`, `editor::launch(...)`, `ratatui::init()`, clear, `app.refresh_git()`, and redraw. Any launch error goes to the status line. Spawn the watcher after the app is built and keep the returned value alive.
5. `README.md`: what it is, build (`cargo build --release`), run (`./target/release/agtx [path]`), config location and full default TOML, keys table, and the note that it is read-only.
6. Tests:
   - `should_ignore` for `.git/index`, `target/debug/x`, `node_modules/a`, `.DS_Store`, a normal `src/main.rs`.
   - `substitute` with and without a line number.
   - app `FsChanged` marks a relative path recent and refreshes; `prune_recent` removes entries older than 10 seconds.
   - render smoke test with a recent file shows `●`.

Acceptance: `cargo test` passes; `cargo build --release` succeeds; in a temp repo, editing a file shows the tree refresh without pressing `r`, and `e` opens nvim on the selected file.
